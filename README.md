
# CodeAlpha Frontend Development Internship Projects

## About

This repository contains three frontend development projects completed as part of my **CodeAlpha Virtual Frontend Development Internship (November 2026)**.

The projects are developed using HTML, CSS and JavaScript to practice and improve my frontend development skills.

## Projects

### 1. Personal Portfolio Website
A responsive personal portfolio website that showcases my profile, skills, projects and contact information.

**Features:**
- Home and About sections
- Skills and Projects sections
- Experience and Contact sections
- Responsive navigation menu
- Smooth scrolling and hover effects

### 2. Image Gallery
An interactive and responsive image gallery that displays images in an organized grid layout.

**Features:**
- Image grid layout
- Category-based image filtering
- Lightbox image preview
- Next and Previous navigation
- Keyboard navigation
- Hover effects
- Responsive design

### 3. Calculator
A simple and responsive calculator built using JavaScript.

**Features:**
- Addition, subtraction, multiplication and division
- Decimal number calculations
- Percentage calculation
- Clear and Delete functionality
- Positive and negative number support
- Keyboard support
- Responsive design

## Technologies Used

- Visual Studio Code
- Git and GitHub
